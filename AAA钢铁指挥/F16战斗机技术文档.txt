本文件汇总 F-16(盟军)战斗机的全部设定与代码位置,供后续开发直接查用。
苏-35(苏军)与 F-16 除阵营/贴图/名字外,战斗逻辑完全一致(共用 AIR_WPN_TYPES)。
改代码前先通读。

-------------------------------------------------------------------------------
一、定位与基本属性
-------------------------------------------------------------------------------
  阵营:盟军专属(allies)。苏军对应机型 = 苏-35。
  生产来源:机场(airfield,由机场建筑车 E 展开)。
  属性(config.js getUnitDefs('allies').f16):
     价格 12000     建造 20秒      血量 150      移速 150
     护甲 铸铁甲(castiron)         无武器(range=0,damage=0,rof=0)
     fly:true(空军单位)             slotCost:1(占1个停机位)
  本质:一种特殊的 Unit。走独立逻辑(updateAircraft),不参与地面单位战斗系统。

-------------------------------------------------------------------------------
二、机场生产与停机位
-------------------------------------------------------------------------------
  机场 BLD_DEFS.airfield(占地2x3,血750,木甲,train=['f16','su35']):
    - 生产入口:选中机场,ui.js 的 train 循环按 getUnitDefs(playerFaction)[t]
      过滤阵营单位(盟军只见 F-16)。
    - canTrain/canProduceIn 判定:defName==='airfield' &&
      AIR_FACTION[type]===unitFactionOf(team) && airfieldUsedSlots(b)<AIRFIELD_CAPACITY。
    - 停机位:AIRFIELD_CAPACITY=4 格;占用 = 存活飞机(homeBase 归属,停驻+出击都算)
      + 队列格数(airfieldUsedSlots),下单即占位,满 4 拒绝生产。
    - 生产即停驻:updateBuilding 产出后直接 parkAircraft(u,b)(不设集结点)。
      每架 spawnUnitNear 里记 u.homeBase=b(绑定生产机场)。
    - 停机位小格:机场上只显示"停驻中"的飞机(飞出去格子即消除)。

-------------------------------------------------------------------------------
三、停驻 / 释放 / 返场
-------------------------------------------------------------------------------
  parkAircraft(u,b):
    - u.parked=true;坐标归机场中心;清 order/路径/目标/patrol/_returning;
      补满 aaAmmo=AA_AMMO、agAmmo=AG_AMMO;清 _needRefuel/_refuelAfterMove。
    - 停驻飞机:不渲染/不上小地图/不可点选(entityAt、boxSelect 跳过)/不参战。
  releaseAircraft(b):选中机场「释放战斗机」→ 所有停驻飞机在机场周围散开,
    u.patrol={机场中心},在机场上空盘旋;出击也补满弹。
  返场触发:
    - 手动:选中飞机右键己方机场(giveOrder 分支)。
    - 自动:任一弹舱(A-120c 或 A-174b)打空 → planeNeedRefuel(u)。
    - 机场被摧毁:destroyBuilding 里停驻飞机自动释放(失去母港无法再返场)。

-------------------------------------------------------------------------------
四、移动与盘旋(基础设定)
-------------------------------------------------------------------------------
  右键地面 = orderMove 对 fly 单位改 u.patrol={点击点},在该点上空盘旋(不落地)。
  orbitAround(u, center, dt):绕 center 半径 PLANE_PATROL_R=48 绕圈。
    - 速度 = 逆时针切向 + 径向修正;err=(R-d)/R,太近向外/太远向内。
    - 偏离轨道>85% 直接径向飞向轨道(快速收敛);圆心 d<2 先沿 facing 挪到半径4。
  攻击 vs 盘旋:有攻击目标时**脱离盘旋** seekVelocity 直线飞向目标接战;
  无目标/无弹才回到盘旋。

-------------------------------------------------------------------------------
五、攻击方式总览
-------------------------------------------------------------------------------
  手动(默认):右键敌机 → A-120c;右键地面/建筑 → A-174b。
  自动分配 / 倾泻:需先装雷达火控,再按 1号/2号 模式键切换(见第七节)。
  前提:对应导弹包已装、有弹;手动两发之间冷却 AIR_MISSILE_CD=1.2s。
  地面部队对飞机无效:findEnemyNear/碉堡/进驻/右键都排除 fly;
  只有战斗机装 A-120c 后才能空对空。

-------------------------------------------------------------------------------
六、A-120c 空对空导弹包
-------------------------------------------------------------------------------
  价格 1000 / 安装 15秒 / 弹舱 2 发。
     AA_RANGE=300(射程)  AA_DAMAGE=200  AA_SPEED=180
     贴图 aim120c_field.png(机头朝上,渲染长 24px)
  只打飞机:手动发射条件 = u.target.fly && u.aa && u.aaAmmo>0 && u.aaCd<=0
    && dist <= airMissileEffRange(u, AA_RANGE, target)。
  orders.js orderAttack 里 enemy.fly → A-120c 分支。

-------------------------------------------------------------------------------
七、A-174b 空对地导弹包
-------------------------------------------------------------------------------
  价格 1000 / 安装 15秒 / 弹舱 2 发。
     AG_RANGE=310(射程)  AG_DAMAGE=650  AG_SPEED=150
     贴图 aim174b_field.png(机头朝上,渲染长 28px)
  只打地面/建筑:手动发射条件 = !u.target.fly && u.ag && u.agAmmo>0 && u.agCd<=0
    && dist <= airMissileEffRange(u, AG_RANGE, target)。
  威力大(650),拆建筑/清地面的主力。

-------------------------------------------------------------------------------
八、空军导弹弹体(不可干扰/不可反导/不可挡弹)
-------------------------------------------------------------------------------
  弹体 = Missile 类 + this.air=true(spriteType 'a120c'|'a174b')。
  launchAirMissile(u, target, kind):按 kind 建弹并覆盖 speed/maxSpeed/maxRange/
    damage(先加速后匀速,限转角追踪)。
  与地面 TOW/长钉 的区别:
    · 不可被 T84BM 红外干扰(IR 只认 spriteType==='tow')。
    · 不可被 APS 自主防御反导(APS 条件收紧为"只反 tow")。
    · 不被任何目标挡弹(updateMissiles 的 m.air 分支不查 atgmBlocker)。
    · 命中/超射程/目标死亡 → explodeATGM 爆炸(AOE 范围伤,只打敌方地面,飞机免疫)。
  渲染 drawMissiles:朝上贴图 rotate(m.ang+π/2),长轴按高对齐到目标长度。

-------------------------------------------------------------------------------
九、雷达火控(射程+30 + 三态攻击模式)
-------------------------------------------------------------------------------
  价格 2500 / 安装 15秒。
  效果 1:所有己方导弹有效射程 +30(RADAR_RANGE_BONUS)。
  效果 2:解锁两个模式键(1号→A-120c / 2号→A-174b),按键循环:
      手动(0)→ 自动分配(1)→ 倾泻(2)→ 手动(仅对应武器已装时按键可用)。
  updatePlaneRadarWeapon(u, dt, 'aa'|'ag'):
    · 探测圈 = 以自己为圆心、半径 = 武器有效射程。
      AA 圈查敌方飞机;AG 圈查敌方地面单位+建筑。
    · 每帧重建当前圈内 Set,与上帧(u.aaScan/u.agScan)差分:
        新进入敌人:自动模式打1发(lastFire[单位]=time);倾泻模式 while(有弹)全打光。
    · 自动补刀:lastFire(Map,单位做键)中仍在圈内存活、距上次≥
      AIR_MODE_AUTO_COOLDOWN=2.8秒 → 再打1发,直到炸死或弹舱空。
    · 弹舱打光自动 planeNeedRefuel 返场。
  渲染:选中自动/倾泻模式飞机,drawSel 画该武器探测圈虚线圆。

-------------------------------------------------------------------------------
十、涂层更新(敌方雷达式探测 -50)
-------------------------------------------------------------------------------
  价格 1200 / 安装 15秒。
  效果:本机进入任何敌方雷达式探测时,等效对方探测范围缩小 50px。
  核心 airMissileEffRange(u, base, target):
        return base + (u.radar ? 30 : 0) - (target.coat ? 50 : 0);
    (己方雷达 +30 在射击方算;目标涂层 -50 在被探测方算。)
  未来 SAM/雷达系统只要走 airMissileEffRange 或等效判定,涂层自动生效。

-------------------------------------------------------------------------------
十一、返场补弹(任一弹舱打空即返场,玩家指令优先)
-------------------------------------------------------------------------------
  1. 触发:任一弹舱归零 → planeNeedRefuel(u):
     置 _needRefuel=true;若不在"移动后返场"状态则立即 _returning=true。
  2. 玩家移动指令优先:返场途中/打空后玩家右键移动(orderMove),置
     _refuelAfterMove=true 并取消立即返场;先飞到新盘旋点盘旋约 2 秒再自动返场。
  3. parkAircraft/releaseAircraft 都补满 aa/ag 弹舱。
  4. 机场回血:停驻飞机每秒 +10 生命(维修厂修不了飞机)。

十三、经验与踩坑(F16 专属)
-------------------------------------------------------------------------------
  1. 停机位按格算:airfieldUsedSlots = 存活飞机(停驻+出击)+ 队列,下单即占位。
  2. 生产即停驻:不设集结点;要上战场先「释放战斗机」。
  3. 盘旋圆心奇点:释放落点在圆心会因径向方向抖动卡死——orbitAround d<2 时沿
     facing 挪到半径 4px;stuckT 判定加 !u.fly(飞机不参与地面脱困)。
  4. 自动分配"新进入"判定:必须用上一帧圈内集合做差分,否则导弹一直在圈内会
     每帧全打光(与 APS 的 apsEngaged 同理);lastFire 及时删死亡/出圈单位。
  5. 手动缺冷却会一帧清空弹舱:aaCd/agCd 每发 1.2s 限速。
  6. 双弹舱返场:必须任一归零即返场,别只判 aaAmmo。
  7. APS/IR 天然免疫:A-120c/A-174b 走 Missile.air + spriteType 非 tow,不会被
     T84BM 干扰、不会被 APS 反导、不被挡弹。
  8. 测试建敌机:苏军要用 su35,别用 f16 配 team 1(getUnitDefs 崩)。
  9. 版本号:改完 GAME_VERSION +1,index.html 全部 ?v= 同步 +1。
