# 迷你红警

一个基于 HTML5 Canvas 的迷你即时战略（RTS）游戏，采用经典红警式基地建造、资源采集与部队作战玩法。纯前端实现，无第三方依赖，无需构建。

## 功能

- 2~4 支队伍对战，支持玩家 + 电脑对手的自由组合
- 盟军 / 苏军两大阵营，双方拥有不同的兵种与科技
- 随机生成的战场地形：草地、水域、树林、金矿
- 完整的基地建造链：建造厂、发电厂、兵营、战车工厂、精炼厂、碉堡、维修厂、实验室
- 采矿车自动采集金矿并送回精炼厂换钱
- 电力系统：电力不足时建造、生产与研究都会减速
- 建筑升级、兵营 / 战车工厂升级、实验室科技研发
- 电脑 AI 按时间线发展经济、扩军，并周期性地进攻和回防
- 编队、框选、集结点、出售建筑、基地车展开等经典 RTS 操作

## 运行

游戏是纯静态页面，不需要安装依赖或执行构建：

1. 将 `index.html` 放到 `新红警/` 目录内（与 `css/`、`js/`、`img/` 同级）。
2. 用任意静态服务器指向 `新红警/` 目录，或在浏览器中直接打开该 `index.html`。

> 注意：当前仓库把页面入口放在仓库根目录，而样式、脚本和图片位于 `新红警/` 下，根目录 `index.html` 里引用的 `css/...`、`js/...` 路径与资源位置不一致，直接打开根目录文件会找不到资源。

## 开始游戏

主菜单中可完成以下设置：

- 选择地图：标准战场、富饶之地、峡谷纵横、开阔平原
- 调整队伍数量：2~4 队
- 每队选择阵营（盟军 / 苏军）、分组（A~D）与角标颜色
- 设置我方开局资金（5000 ~ 100000），资金越多难度越低
- 在预览地图上点击出生点圆点，为各队伍分配出生位置

游戏目标是摧毁敌方所有建筑；我方所有建筑被摧毁则失败。

| 右键 | 移动 / 攻击 / 设置集结点 / 指定矿车采矿或倒矿 |

## 建筑与单位

### 建筑

- 建造厂：基地核心，负责建造其它建筑，不可出售
- 发电厂：提供电力，可升级两级，升级后额外增加电力和收入
- 兵营：训练步兵；升级后解锁阵营高级步兵
- 战车工厂：生产主战坦克、采矿车；升级后解锁高级坦克与基地车
- 精炼厂：接收采矿车运回的金矿并转换为资金
- 碉堡：固定防御炮台，自动攻击射程内敌人
- 维修厂：自动修复受损建筑，并治疗范围内的己方单位
- 实验室：研发通用科技和阵营专属科技，耗电 100

建筑必须贴近己方已有建筑才能放置；建筑在建造中和生产单位时，电力不足会使进度减半。

### 单位

- 动员兵 / 北约士兵：基础步兵
- 灰熊坦克 / 犀牛坦克：主战坦克
- 采矿车：自动采集金矿并运送回精炼厂
- 基地车：可在 3x3 空地上展开成新的建造厂
- 盟军高级单位：艾布拉姆斯主战坦克、外骨骼大兵
- 苏军高级单位：T90 主战坦克、磁暴步兵

### 升级与科技

- 战车工厂升级：$500 / 10 秒，解锁高级坦克与基地车
- 兵营升级：$250 / 9 秒，解锁阵营高级步兵
- 发电厂升级：$100 / 级，最多 2 级
- 通用科技：发电改进、矿石精炼、高级炮台
- 盟军专属科技：贫铀利用（艾布拉姆斯增伤、减伤）
- 苏军专属科技：反应装甲（T90 获得护盾并免疫一次致命伤害）

## 实现要点

- 纯 JavaScript + Canvas 2D 渲染，脚本按 `index.html` 中的顺序加载
- 64x48 格地图，32 像素/格，程序化生成障碍与矿脉，并保证出生点周围留出空地
- 单位寻路使用 BFS，战斗索敌与局部防挤压使用空间网格
- 批量移动采用环形阵型，配合速度平滑和侧向分离力，减少单位扎堆和抖动
- 采矿车会自动避开已被占用的矿脉，并优先从建筑南侧卸矿口倒矿
- 电脑 AI 分阶段发展：先保证电力，再依次建设兵营、战车工厂、精炼厂和碉堡，后期持续扩军并按波次进攻
