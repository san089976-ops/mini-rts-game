# 钢铁指挥

一个基于 HTML5 Canvas 的即时战略（RTS）游戏。纯前端实现，无第三方依赖、无需构建，打开 `AAA钢铁指挥/index.html` 即可游玩。

## 功能

- 2~8 支队伍遭遇战，支持玩家 + 电脑对手自由组合
- 盟军 / 苏军两大阵营，双方拥有不同的兵种、坦克升级链与空军单位
- 内置多张程序生成地图：标准战场、富饶之地、峡谷纵横、开阔平原、海上争霸
- 支持地图文件夹加载自制地图，并内置可视化地图编辑器
- 完整基地建造链：建造厂、发电厂、兵营、战车工厂、精炼厂、碉堡、维修厂、实验室、船坞、机场
- 采矿车自动采集金矿并送回精炼厂换钱；电力不足时建造、生产与研究减速
- 建筑升级、实验室科技、坦克升级链、单位武器/模块安装
- 海战地图：船坞、驱逐舰、运输艇抢滩登陆
- 空军：机场、F-16 / 苏-27 战斗机、空对空/空对地导弹、雷达火控与出击规划
- 电脑 AI 按难度发展经济、扩军、进攻与回防；海战图有专门的登陆 AI
- 编队、框选、集结点、出售建筑、基地车展开等经典 RTS 操作

## 快速开始

游戏是纯静态页面，不需要安装依赖或执行构建：

1. 用浏览器直接打开 `AAA钢铁指挥/index.html`。
2. 或把 `AAA钢铁指挥/` 作为静态站点根目录，通过任意静态服务器访问 `index.html`。

建议使用 Chrome / Edge。读取 `map/` 文件夹扫描自制地图依赖浏览器的 File System Access API；也可直接使用地图编辑器保存地图（自动生成 `map/index.js`）。

## 对战设置

主菜单支持以下设置：

- 地图：内置地图或 `map/` 文件夹中的自制地图
- 队伍数：内置地图 2~8 队；自制地图由保存的出生点数决定
- 每队阵营：盟军 / 苏军
- 分组 A~D：与玩家同组视为同盟，其余为敌对
- 电脑难度：简单 / 中等 / 残酷，中等与残酷会研发实验室科技
- 队伍颜色：9 种可选
- 我方开局资金：5000 ~ 100000
- 出生点：先点击队伍按钮，再点击预览地图上的出生点圆点分配点位（不可重复）

胜利条件：摧毁敌方所有建筑；我方所有建筑被摧毁则失败。

## 操作说明

| 操作 | 功能 |
| --- | --- |
| 左键 | 选择 / 框选 / 建造放置 |
| 右键 | 移动 / 攻击 / 设置集结点 / 上船 / 采矿指令 |
| Ctrl+右键 | 强制攻击；点空地 = 攻击移动 |
| Shift | 追加选择 |
| Tab | 全选作战单位 |
| Esc | 取消放置 / 取消出售 / 暂停游戏 |
| 空格 | 视角回到基地 |
| WASD / 方向键 | 滚动视角 |
| 鼠标中键 | 按住拖动地图 |
| Q / W / E / R / T / Y / U / I | 直接开始建造对应建筑 |
| Ctrl+1~9 | 编队；单独按 1~9 选择编队，快速连按两次跳转视角 |
| 小地图点击 / 拖拽 | 快速移动视角 |

基地车 / 机场建筑车选中后按 `E` 展开；未选中时 `E` 作为战车工厂建造快捷键。建筑与单位的详细操作说明可在游戏内“帮助”弹层查看。

## 建筑

- 建造厂：基地核心，负责建造其它建筑，不可出售；升级后解锁机场建筑车
- 发电厂：提供电力，可升级两级，每级提高电力与收入
- 兵营：训练步兵；升级后解锁阵营高级步兵
- 战车工厂：生产主战坦克、采矿车与基地车；升级后解锁高级战车
- 矿石精炼厂：接收采矿车运回的金矿并转换为资金
- 碉堡：固定防御炮台，自动攻击射程内敌人
- 维修厂：治疗周围两格内的己方单位
- 实验室：研发通用与阵营科技，耗电 100
- 船坞：只能整块建在距己方建筑 8 格内的水面，生产驱逐舰与运输艇
- 机场：由机场建筑车展开，生产 F-16 / 苏-27 战斗机，共 4 个停机位
- 中立建筑：学校、医院、别墅、综合商业体、核电站、五角大楼等，可查看、进驻或摧毁

## 单位

- 盟军：北约士兵、M60 主战坦克、采矿车、基地车、机场建筑车
- 苏军：动员兵、T54 主战坦克、T62、采矿车、基地车、机场建筑车
- 高级步兵：盟军外骨骼大兵 / 苏军磁暴步兵（升级兵营后解锁）
- 高级战车（升级战车工厂后）：盟军艾布拉姆斯、梅卡瓦 MK4、布拉德利、黄鼠狼、勒克莱尔、豹2A4、挑战者、美洲狮；苏军 T90、T84BM、T72、T80、B11
- 海军 / 两栖：驱逐舰、运输艇（可装载 12 点地面单位）
- 空军：盟军 F-16、苏军苏-27，可安装空对空 / 空对地导弹包，飞越一切地形

## 升级与科技

- 建造厂升级：解锁机场建筑车
- 兵营升级：解锁高级步兵
- 战车工厂升级：解锁高级战车
- 发电厂升级：最多 2 级
- 坦克升级链：挑战者 2 次升级；T54 二选一升级 T54B / T55AM；T62 → T64 → T64B → T64BM；T72 → T72B → T72BVM；T80 → T80B → T80U → T80BVM；T90 → T90M
- 单位模块：反坦克导弹、自主防御系统（APS）、TUSK、火炮升级、反应装甲、红外干扰装置、雷达火控、涂层更新等
- 实验室科技：发电改进、矿石精炼、高级炮台，以及盟军专属的贫铀利用

具体数值以游戏内面板为准。

## AI

- 简单：按时间线发展经济与扩军，周期进攻
- 中等：会建造实验室并研发科技，收入有加成
- 残酷：发展更快、兵力更多、进攻更频繁，收入加成最高
- 海战图：运输艇装船抢滩登陆，驱逐舰护航/压制，已登陆部队定期重新集结进攻

## 地图编辑器与自制地图

- 主菜单点击“打开地图编辑器”，或直接访问 `AAA钢铁指挥/map-editor.html`
- 编辑器可绘制地形、金矿、建筑、单位与出生点，并保存到 `map/` 文件夹
- `map/index.js` 列出可加载的自制地图；地图文件会被自动注入并出现在地图列表

## 实现要点

- 纯 JavaScript + Canvas 2D 渲染，脚本按 `index.html` 顺序加载
- 8 方向 A* 网格寻路（二叉堆开放列表），配合路径缓存、按帧寻路预算与寻路失败退避
- 攻击指令使用共享流场寻路，多单位追击同一目标时复用整图代价场
- 航点平滑：将 A* 阶梯路径压缩为视线可达的长直线段
- 空间网格索敌与分离，双圆胶囊碰撞与刚性位置修正
- 树木可被重型单位碾倒，地图变化后自动使寻路缓存失效
- 载具按车头方向转向，长条形车身使用车头/车尾双圆碰撞近似
