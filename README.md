# 迷你红警

一个基于 HTML5 Canvas 的迷你即时战略（RTS）游戏，纯前端实现，无第三方依赖，无需构建。

## 运行

直接打开 `rts/index.html`，或用任意静态服务器托管 `rts/` 后访问。

## 功能

- 遭遇战模式：地图选择、队伍数量、出生点、阵营、分组、颜色、电脑难度配置
- 建造与生产：发电厂、兵营、战车工厂、精炼厂、碉堡、维修厂、实验室、船坞
- 单位系统：步兵、坦克、采矿车、基地车、高级步兵、重型坦克、驱逐舰、运输艇
- 海战与运输：水域地图、船坞、驱逐舰、两栖运输艇、装载与卸载
- AI 对手：独立经济、建造规划、研发科技、进攻与防守
- 操作：左键选择/框选、右键指令、快捷键建造、编队、小地图、中键拖拽地图
- 背景音乐：4 首循环播放，支持切换与开关

## 目录

- `rts/index.html` 页面入口
- `rts/css/` 样式
- `rts/js/` 游戏逻辑
- `rts/img/` 资源
